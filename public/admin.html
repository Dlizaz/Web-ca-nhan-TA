Ảnh sẽ được tự động thu nhỏ về 32×32px khi tải lên (con trỏ ảnh lớn sẽ bị trình duyệt bỏ qua). Nên chọn ảnh có nền trong suốt để không bị viền vuông.

Widget Discord

Chế độ này lấy dữ liệu trực tiếp qua Lanyard API (miễn phí, không cần bot). Tài khoản Discord của bạn cần tham gia server Lanyard (discord.gg/lanyard) thì trạng thái mới cập nhật được.

Khung ảnh đại diện (avatar)

Nên dùng ảnh PNG nền trong suốt, phần trang trí (hoa, tim, sao...) nằm quanh viền để tràn ra ngoài avatar tròn.

Chế độ này dùng chung "Discord User ID" đã nhập ở mục Widget Discord phía trên. Khung sẽ tự hiện đúng khung trang trí (avatar decoration) mà tài khoản Discord của bạn đang gắn — nếu bạn tháo khung trên Discord, nó cũng biến mất khỏi trang.
